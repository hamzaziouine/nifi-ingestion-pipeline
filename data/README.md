# Sample data

| File | Content |
|---|---|
| `sample/cars_full.csv` | the 398 cars of the Auto MPG dataset in the CSV layout the flow validates (6 have no horsepower, 79 are from Japan) |
| `sample/cars_malformed.csv` | 20 valid rows and 5 broken ones (text in an int column, origin outside the enum, missing MPG, missing column, empty origin) |
| `sample/web_cars.json` | 10 cars in the raw JSON shape for the HTTP entry point; the last one has origin code `4`, which maps to nothing and is quarantined |

All three are generated by `scripts/make_sample_data.py` from the original file.

Source: Quinlan, R. (1993). *Auto MPG*. UCI Machine Learning Repository.
https://doi.org/10.24432/C5859H. Licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes: car names title-cased,
origin codes replaced by labels, missing horsepower (`?`) left empty, columns renamed;
the malformed rows in `cars_malformed.csv` are made up for testing.
